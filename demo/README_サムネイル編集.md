# デモ版：サムネイル編集

本番のファイル・GAS・接続設定には反映していません。

## 追加した機能

- 記事の新規作成・編集画面に「一覧用サムネイル」を追加。
- 初期状態はトップ画像を使用。サムネイル専用画像のアップロード・URL指定にも対応。
- 一覧の画像枠は16:9に統一。ドラッグ、ズーム（1〜3倍）、横位置・縦位置のスライダーで調整。
- 「画像全体を表示（余白あり）」で、縦長チラシも欠けずに表示。
- 一覧と同じ描画方法のプレビュー、位置・ズームのリセット。
- 設定を下書き・非公開・予約・公開の保存データに含め、再編集時に復元。
- トップ画像・本文画像の順番、本文中の画像番号は従来どおり。

## すぐ操作して確認する（ローカル）

リポジトリのフォルダで次を実行します。

```powershell
node demo/tests/thumbnail-preview-server.cjs
```

http://127.0.0.1:4175/demo/ を開き、任意のメール形式の文字列とパスワードでログインしてください。
例：preview@example.test / preview

「Admin」→「新規記事」、または「記事一覧」→サンプル記事で操作できます。
写真・縦長チラシのサンプルがあります。投稿・画像アップロードはメモリー内で完結し、外部APIや公開サイトへ保存されません。
この確認用データはサーバーを終了すると消えます。確認用サーバーを公開サーバーとして使用しないでください。

## 公開デモへの反映順序

今回の変更はフロント側とGAS側の両方の更新が必要です。**デモ用GASを先に更新してください。**
GASを更新しないまま新しい画面で記事を保存すると、更新が必要な旨を表示して保存を止めます。

1. デモ用スプレッドシートに紐づくApps Scriptプロジェクトの、現在のソースをバックアップします。
2. **デモ用**の `Code.gs` を、このパッケージの `demo/Code.gs` に差し替えて保存します。
3. Apps Scriptの「デプロイ」→「デプロイを管理」から、デモで使用中のウェブアプリを編集し、新しいバージョンとしてデプロイします。既存のURL・アクセス権・スクリプトプロパティを維持してください。
4. `demo/config.js` のGAS URLに `?action=ping` を付けて開き、`"thumbnailEditing":1` が含まれることを確認します。
5. GitHub側の以下のファイルを差し替えます。
   - `demo/index.html`
   - `demo/styles.css`
   - `demo/thumbnail.js`（新規）
   - `demo/app.js`
   - `demo/sw.js`
6. 公開デモを開き直します。インストール済みPWAは一度終了して再起動してください。

保存先の `posts` シートには `thumbnailJson` 列が自動追加されます。手動で列を作成したり、既存記事を一括変換したりする必要はありません。
設定のない既存記事は先頭画像を使用します。一覧の画像枠は既存記事も16:9に揃います。
古い画面からの保存でサムネイル設定が消えないよう、GAS側で未指定の設定を維持します。

### 公開デモでの確認項目

1. 新規記事でトップ画像を追加し、サムネイルをドラッグ・ズームして下書き保存。
2. 記事一覧から再編集し、位置・ズームが復元されることを確認。
3. サムネイルだけ別画像に変更して保存。記事を開いたときは元のトップ画像であることを確認。
4. 縦長チラシを「画像全体を表示」にして、一覧で文字が欠けないことを確認。
5. 「トップ画像を使う」に戻して保存し、元の画像に戻ることを確認。
6. スマートフォンでも画像のアップロード・ドラッグ・スライダーを確認。

公開デモで問題がないことを確認後、本番への適用を別途行います。
