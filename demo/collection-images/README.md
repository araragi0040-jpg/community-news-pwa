# カード画像の手動配置

このフォルダにPNG / JPG / WEBP / GIFのカード画像を置き、DEMOのWeb公開先へアップロードします。

- 推奨ファイル名：`sake-2026.webp`、`bbq-2026.png`（半角英数字・ハイフン・アンダースコア）
- 管理画面へ入力するパス：`collection-images/sake-2026.webp`
- 縦長・横長いずれも画像全体を表示します。カード同士の見栄えを揃えるには同じ縦横比を推奨します。
- 獲得された画像は上書き・削除しないでください。別の年には別の画像ファイル名を使用します。
- 一般公開される静的画像です。未獲得カードのAPIは画像パスを返しませんが、URLを知っている人の直接アクセスまでは制限できません。

ローカルプレビューのサンプル画像は`demo/tests/fixtures/`にあり、本フォルダや公開用ZIPには含めません。
