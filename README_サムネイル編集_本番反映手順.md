# 本番環境：サムネイル編集の反映

本番ニュースサイトに、記事一覧用サムネイルの専用画像・16:9範囲・位置・ズームの編集を追加します。先に本番GASを更新し、`thumbnailEditing: 1` を確認してから、GitHub Pagesのファイルを反映してください。画面側は対応GASが未更新の場合、記事の保存を止めて更新案内を表示します。

## 1. 本番GASを更新

1. 本番スプレッドシートに紐づくApps Scriptプロジェクトを開き、現在の `Code.gs` をバックアップします。
2. このパッケージの `Code.gs` で、本番プロジェクトのソースを置き換えて保存します。デモ用プロジェクトには適用しないでください。
3. 「デプロイ」→「デプロイを管理」から、現在本番で使っているウェブアプリのデプロイを編集し、新しいバージョンとしてデプロイします。既存のデプロイURL、アクセス権、スクリプトプロパティは維持します。
4. `config.js` に記載された本番GAS URLの末尾に `?action=ping` を付けて開き、応答に `"thumbnailEditing":1` があることを確認します。

## 2. 本番GitHub Pagesを更新

リポジトリ `araragi0040-jpg/community-news-pwa` の本番ルートに、次のファイルを反映してください。

- `index.html`
- `styles.css`
- `thumbnail.js`（新規）
- `app.js`
- `sw.js`

`config.js` は既存の本番設定をそのまま使います。このパッケージには含めていません。反映後、GitHub Actions の Pages デプロイ完了を待ち、本番URLを再読み込みしてください。

## 3. 本番で確認

1. 管理画面で記事を開くか、新規作成を開き、サムネイル設定が表示されること。
2. 位置・ズーム・全体表示を調整し、下書き保存後に編集を開き直して設定が復元されること。
3. 専用サムネイル画像を使っても記事本文のトップ画像が変わらないこと。
4. 記事一覧とスマートフォンで16:9表示を確認すること。

## データの扱い

GASは記事シートに `thumbnailJson` 列を自動追加します。既存の行や記事画像は書き換えません。設定がない記事はこれまでどおり先頭画像を使い、古い画面からの更新時も保存済みのサムネイル設定を維持します。公開済みの記事も一覧の枠は16:9になり、未設定の位置・ズームは中央・等倍で表示されます。

このZIPには本番設定の `config.js` は含めていません。`Code.gs` は本番用として、分析設定に関する本番コメントを保っています。
